# 裁决轮改回固定用 opus — 小 spec

日期:2026-10-03。

## 目标

同日早些时候把评审链的裁决轮改成了「用主对话当前的模型」(脚本里省略 `model`)。主对话用最高档模型时,每个单元的裁决都落在它上面,消耗太大。Tony:「把审查模型放回opus吧,fable消耗量太大了,默认主模型为审查模型不太行」。改回:裁决轮固定 `opus` + `high`,脚本里显式写 `model: 'opus'`。

## 新写法(README 第三节与七.4;模板里对应各处同样改)

- 分工表评审行:`opus` 子代理(盲审、续挖、裁决都是)。
- 档位表标题去掉「裁决轮的 `model` 例外,见规则 2」;裁决轮一行的 model 列写 `opus`。
- 规则 2 的裁决轮:链的最后一轮(`opus` + `high`:脚本里显式写 `model: 'opus'`,不随主对话的模型变;带全链发现出结论,不占镜头)。
- 规则 3:评审链每一轮都用 `opus` + `high`(盲审 3 个)。
- 规则 4「裁决模型」一行保留,理由句改成:`opus` 别名解析到哪一代由服务端决定,不记就分不出评审模型换代。
- 「逐 stage 显式写 `model` + `effort`」那句去掉裁决轮例外,改成「裁决轮也不例外,写 `model: 'opus'`」。
- 七.4 步骤里两处:评审链「盲审、续挖、裁决都是 `opus`」;「末轮裁决用 `opus` + `high`」。
