# 记录文档里的内部标识换成中性叫法 — 小 spec

日期:2026-10-03。

## 目标

本仓是公开仓库。`docs/` 下更早的记录里留有只属于内部的标识。把它们换成中性叫法:记录仍然读得通,但外人看不出具体的内部名字。README 与 `plugins/` 不动。

## 做法

- 用脚本按固定对照统一替换:内部域名与内网地址、带用户名的本机路径与个人目录、组名、同事的名字与账号编号、内部工具包与内部项目的名字、内部组件名、内部分支名。
- Tony 原话引用里被替换的词用〔〕标注。
- 一份文件名带内部项目名的 spec 改名,索引链接同步。
- 三份评审记录里整段只讲内部副本的章节换成一句结论,原文存在内部仓库。
- 已推送的提交历史不改写。

## 不做

- 混在公开单元记录里的内部副本细节(中性叫法下的文件位置、内部仓库的提交号与版本号)不逐条删:没有名字之后,它们指不到任何具体对象。
- 不改 README、`plugins/`。

## 验收

1. `docs/` 里检索内部域名、内网地址、带用户名的路径、组名、同事名字、内部工具与项目名,零命中。
2. `README.md`、`README.zh-CN.md`、`plugins/` 相对 main 无改动。
3. `docs/` 内的相对链接无断链;证据里的 JSON 行仍是合法 JSON。
4. 公开的名字(本仓插件名、公开产品名、通用默认路径)没有被误换。
